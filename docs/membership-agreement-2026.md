# メンバー加入契約書（第2版）

**博多SKルーキーズ**／Membership Agreement — HAKATA SK ROOKIES

アマチュア草野球チーム「博多SKルーキーズ」（以下「甲」といいます。）と、加入を希望する個人（以下「乙」といいます。）は、乙の甲への加入について、次のとおり契約（以下「本契約」といいます。）を結びます。

> **この契約書は第2版です。**
> 初版は第3条から第11条までに月会費・練習参加費・保険・退団などを直接書いていましたが、2026年12月1日に施行した「チーム規約（第2版）」に内容を移しました。この契約書は、**規約を守る約束と、記入・署名のための書類**という役割にしています。
> 中学生のメンバーにも読んでもらえるよう、法律文書の言い回しをやめて平易な日本語で書いています。扱いの重さは初版と同じです。

## 第1条（目的）

本契約は、乙が甲の活動に参加するにあたって、甲と乙のあいだの約束をはっきり決めておくためのものです。

## 第2条（加入）

1. 乙は、本契約を結んだ日をもって、甲のメンバーになります。
2. 乙は、本契約とチーム規約の内容に同意したうえで、本契約書に署名します。

## 第3条（チーム規約）

1. 甲は、本契約を結ぶにあたり、乙に対して「**博多SKルーキーズ チーム規約（第2版・施行日 2026年12月1日）**」を交付します。
2. **チーム規約は、本契約の一部をなします。** 乙は、規約を守るものとします。
3. 次のことについては、**チーム規約の定めによります。**
   費用（第5条〜第8条）／保険と自己責任（第9条）／安全（第10条）／活動への参加（第11条）／ユニフォーム・装備（第12条）／リーグ戦と1軍登録（第13条）／禁止事項（第14条）／ハラスメント（第15条）／交際（第16条・第17条）／規約違反への対応（第18条）／退団（第19条）／休会（第20条）／氏名・写真・動画の公開（第21条）／個人情報（第22条）／メンバー専用アプリ（第23条）
4. 本契約の定めと規約の定めが食い違う場合は、**本契約を優先**します。

## 第4条（費用）

金額を知らないまま署名することがないよう、主な費用をここにも書いておきます。くわしくは規約 第5条〜第8条をご覧ください。

| | 金額 | 備考 |
|---|---|---|
| 入会費 | **2,000円** | 初回のみ |
| 月会費 | **月額 1,000円** | 原則 毎月初め。むずかしいときはご相談ください |
| グラウンド代（日中 2時間） | 一般 600円／中高生 500円 | 1人あたり。人数に関わらず一律 |
| グラウンド代（日中 4時間） | 一般 700円／中高生 500円 | |
| グラウンド代（ナイター） | 一般 1,000円／中高生 700円 | |
| 試合の日 | 上記に **1人 +100円** | 日中・ナイターとも。中高生も同じ |

1. 月会費は、活動に1度も参加しなかった月も発生します。支払いがむずかしい月は、事前に代表にお申し出ください（規約第5条）。
2. 公園でのキャッチボールなど、球場を借りない活動は無料です。
3. **ユニフォームの購入は強制ではありません**（規約第12条）。高額な年会費や、道具の購入ノルマもありません。
4. すでに納めた費用は、理由を問わず返金しません。
5. 金額を変える場合は、**施行日の1か月以上前**にお知らせします（規約第24条3項）。

## 第5条（保険と自己責任）

大事なところなので、規約第9条と同じ内容を契約書にも書きます。

1. 野球は体がぶつかり、硬い用具を使うスポーツです。けが・病気・物の破損が起こりうることを理解したうえで、乙は本契約に同意します。
2. **スポーツ安全保険への加入は任意です。** 甲は、チームとしての保険には加入していません。
3. 中学生・高校生は、福岡市の子ども医療費助成（高校生世代まで、通院は1医療機関あたり月500円まで、入院は自己負担なし）があるため、**加入しなくて構いません。**
4. ただし、助成でまかなえるのは「**自分のけがの治療費**」だけです。他人にけがをさせたとき・他人の物を壊したときの賠償や、後遺障害の補償は対象外です。
5. **保険に加入していない乙が、練習・試合・移動その他甲の活動に関連してけがをし、または物を壊した場合、甲の故意または重大な過失による場合を除き、甲は一切の責任を負いません。** 乙の自己責任で対応していただきます。
6. 乙が保険に加入するかどうかは、本契約書の記入欄でお選びください。

## 第6条（氏名・写真・動画の公開）

1. 甲は、活動の記録と広報のため、練習や試合の写真・動画を、公式サイト・X・Instagramに公開することがあります。
2. 甲は、**氏名（または登録名）・背番号・ポジション・成績を、公式サイトおよび博多ルーキーリーグ公式サイトに掲載することがあります。**
3. 氏名の公開については、本契約書の記入欄で「**本名でよい／登録名でなら／公開しないでほしい**」の3つからお選びください。選んだあとでも、**いつでも変更できます。**
4. **公開を望まない場合も、リーグ戦に出場できます。** 公開に同意しないことで、出場機会やチーム内の扱いが変わることはありません。
5. リーグの規定により、リーグへの選手登録には本名が必要になる場合があります。その場合も、サイトへの表示は前項でお選びいただいた内容に従います。
6. 乙が満18歳未満の場合は、親権者の同意を確認したうえで公開します。
7. くわしくは規約第21条をご覧ください。

## 第7条（個人情報）

1. 乙からいただく個人情報（氏名・居住地・電話番号・緊急連絡先など）は、チームの運営に必要な範囲でのみ使います。
2. 居住地は**市区町村までを必須**とし、それより詳しい住所は任意です。**生年月日の記載は求めません。**
3. 山王公園球場その他の福岡市公共スポーツ施設の予約・利用手続で、施設の管理者から利用者の氏名等の提出を求められた場合は、氏名を提供することがあります。
4. 博多ルーキーリーグに加盟しているため、リーグの運営に対して、選手登録に必要な情報を提供します。
5. **電話番号・住所・緊急連絡先・生年月日を、サイトやSNSに公開することはありません。** 氏名の公開については第6条のとおりです。
6. くわしくは規約第22条と、公式サイトの[プライバシーポリシー](https://hakata-sk-rookies-v2y8.vercel.app/privacy)をご覧ください。

## 第8条（規約違反への対応）

1. 乙が本契約または規約に違反した場合、甲は、違反の内容と程度に応じて、次の対応をとることができます（規約第18条）。
   注意／一定期間の活動停止／**リーグ戦への出場停止**／リーグの登録メンバーから外すこと／**強制退団**
2. 処分を決める前に、**原則として本人に理由を伝え、言い分を聞きます。** ただし、暴力・ハラスメント・規約第17条違反など緊急を要する場合は、先に活動への参加を停止したうえで事情を聞くことがあります。
3. 強制退団となった場合、乙はメンバーの資格を失い、すでに納めた費用は返金されません。

## 第9条（退団・休会）

1. 退団する場合は、代表にお申し出ください。**理由を説明する必要はありません。**
2. **退団は、申し出た月の翌月1日をもって正式に成立します。**（例：11月中に申し出 → 12月1日付で退団）
3. 申し出た月の月会費は発生します。翌月分からは発生しません。未払いの会費・グラウンド代は、退団日までに精算してください。
4. 甲からの連絡（電話・SMS・SNSのダイレクトメッセージ・メールなど通常の連絡手段）に、正当な理由なく30日以上応答がない場合、甲は、乙に退団の意思があるものとみなし、通知をもって退団の扱いとすることがあります。
5. 仕事・学業・けがなどで一定期間活動できない場合は、**休会**（最長6か月・月会費なし）を申し出ることができます（規約第20条）。
6. 再入団は歓迎します。その場合、入会費をあらためていただきます。

## 第10条（未成年の参加）

1. 乙が満18歳未満の場合は、**親権者の同意が必要**です。本契約書の親権者同意欄にご署名ください。
2. 甲は、18歳以上のメンバーが18歳未満のメンバーに対して**交際を求めること、および個人的に二人きりで誘うことを禁止**しています（規約第17条）。違反した場合は、強制退団を含む厳正な対応をとります。
3. 送迎など、やむを得ず二人きりになる場合は、事前に親権者の同意を得るものとします。

## 第11条（契約期間）

1. 本契約は、締結の日から効力を持ち、**期間の定めはありません。**
2. 本契約は、退団（第9条）または強制退団（第8条）によって終了します。

> 初版の第11条は「1年ごとの自動更新」でしたが、更新拒絶の通知をやりとりする運用が実態に合っていなかったため、第2版では期間の定めをなくしました。退団はいつでも申し出られます（第9条）。

## 第12条（契約内容の変更）

1. 規約を変更する場合は、変更する内容と施行日をあらかじめお知らせします（規約第24条）。
2. **本契約書の内容は、甲乙の書面による合意がない限り、変更できません。**
3. 乙の不利益になる重要な変更をする場合は、**あらためて書面で同意をいただきます。**

## 第13条（契約書の保管）

1. 本契約書は**2通**つくり、甲乙が署名（または記名押印）のうえ、各自1通を原本として保管します。
2. 甲乙は、紛失・破損に備えて、保管用のコピーを取ることができます。

## 第14条（協議）

本契約と規約に書かれていないこと、または解釈に疑問が生じたことについては、甲乙が誠意をもって話し合って解決します。

本契約の成立を証するため、本書2通をつくり、甲乙が署名（または記名押印）のうえ、各自1通を原本として保管します。
