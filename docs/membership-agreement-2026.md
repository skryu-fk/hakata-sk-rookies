# メンバー加入契約書（第2版）

**Membership Agreement — HAKATA SK ROOKIES**

アマチュア草野球チーム「博多SKルーキーズ」（以下「甲」という。）と、加入を希望する個人（以下「乙」という。）は、乙の甲への加入に関し、以下の通り本契約（以下「本契約」という。）を締結する。

> **本契約書は第2版である。** 初版（2026年5月）の体裁を引き継ぎ、2026年12月1日施行の「博多SKルーキーズ チーム規約（第2版）」により改定された事項を差し替えたものである。月会費、練習参加費、保険及び退団に関する定めが初版から変更されているため、初版に署名した在籍メンバーについては、別途「規約改定に関する同意書」により同意を得るものとする。

---

## 第1条（目的）

本契約は、乙が甲の活動に参加するにあたり、甲と乙との間の権利義務関係を明確に定めることを目的とする。

## 第2条（加入）

1. 乙は、本契約の締結日をもって、甲のメンバーとして加入するものとする。
2. 乙は、本契約の内容に同意のうえ署名することにより、甲の活動方針、運営規則及び本契約に定める各条項を遵守することを承諾する。
3. 乙は、加入にあたり、入会費として金二千円（¥2,000）を支払うものとする。入会費は初回限りとし、理由の如何を問わず返還しない。

## 第3条（チーム規約）

1. 甲は、本契約の締結にあたり、乙に対し「博多SKルーキーズ チーム規約（第2版・施行日2026年12月1日）」（以下「規約」という。）を交付する。
2. **規約は、本契約の一部を構成する。** 乙は、規約を遵守するものとする。
3. 本契約に定めのない事項については、規約の定めるところによる。本契約の定めと規約の定めが抵触する場合は、本契約を優先する。
4. 規約は、甲の公式サイト（https://hakata-sk-rookies-v2y8.vercel.app/terms）において常時閲覧することができる。

## 第4条（月会費）

1. 乙は、甲に対し、月会費として**金一千円（¥1,000）**を支払うものとする。
2. 月会費の支払方法は、毎月の活動時における甲代表者又はその指定する者への現金手渡しによるものとする。
3. **支払期限は、原則として毎月初めとする。** ただし、支払が困難な事情がある場合は、乙が事前に甲代表者に申し出ることにより、当該月の15日まで、さらにやむを得ない事情があるときは25日まで猶予するものとする。
4. 当該月内に活動への参加が1度もない場合であっても、月会費の支払義務を免除されないものとする。ただし、第16条に定める休会の期間中は、月会費を要しない。
5. 既に納入された月会費は、理由の如何を問わず返還しないものとする。

## 第5条（グラウンド代）

1. 乙は、甲が野球場その他の有料施設を借用して実施する練習又は試合（以下「球場活動」という。）に参加する場合、参加人数にかかわらず1人あたり次表の額を、当日、甲代表者又はその指定する者への現金手渡しにより支払うものとする。

| 区分 | 一般（社会人・大学生等） | 中学生・高校生 |
|---|---|---|
| 日中の練習（2時間） | 600円 | 500円 |
| 日中の練習（4時間） | 700円 | 500円 |
| ナイターの練習 | 1,000円 | 700円 |
| 試合（日中・ナイターを問わない） | **上表の額に1人100円を加算** | **同左（中学生・高校生も加算する）** |

2. 公園その他無料の公共施設において実施するキャッチボール等の練習については、グラウンド代は無料とする。
3. 第1項の額を変更する場合、甲は、施行日の1か月以上前に乙に通知するものとする。
4. 既に納入されたグラウンド代は、理由の如何を問わず返還しないものとする。

## 第6条（活動内容）

1. 甲の通常の活動は、公園等における練習を週1回〜2回、球場活動を月3回〜4回を目安として実施する。
2. 練習の日時・場所・内容については、甲が事前にメンバーに通知するものとする。
3. 天候、施設の都合、参加人数その他やむを得ない事由により、予定された活動を変更又は中止することがある。
4. 甲は博多ルーキーリーグに加盟しており、同リーグの定める日程に従い公式戦を実施する。

## 第7条（リーグ戦及び登録）

1. **乙は、本契約を締結したことをもって、博多ルーキーリーグの登録メンバー（1軍登録）となることを保証されるものではない。**
2. リーグの規定により登録できる人数は最大20名であり、甲の在籍人数がこれを超える場合、甲は、出場状況、練習への参加状況、対戦相手及びチーム編成上の必要等を勘案して登録者を決定する。
3. 登録は固定的なものではなく、甲は随時これを入れ替えることができる。
4. 登録されなかった場合であっても、乙は練習、紅白戦及び練習試合に従前どおり参加することができ、費用その他の取扱いに差異を設けない。

## 第8条（ユニフォーム及び装備）

1. **ユニフォームその他チーム用品の購入は、乙の任意とする。** 甲は、購入を強制せず、購入しないことを理由として出場機会その他の取扱いに差異を設けない。
2. グローブ、バット、ヘルメット等の用具については、甲が貸出用の備品を用意する。乙は、これを丁寧に取り扱うものとする。

## 第9条（遵守事項）

乙は、甲の活動に参加するにあたり、以下の各号を遵守するものとする。

1. 練習及び試合において、他のメンバー、対戦相手、審判その他の関係者を尊重し、安全に十分配慮すること。
2. 野球道具・チーム備品を丁寧に取り扱い、故意又は重大な過失によりこれを破損・紛失しないこと。
3. **参加を予定していた活動を欠席し、又は遅刻する場合は、事前に甲代表者又はチームの連絡網に連絡すること。** 球場は参加人数を見込んで予約し、試合においては打順及び守備を編成するため、無断の欠席・遅刻は、他のメンバーの負担及び1人あたりのグラウンド代に影響する。やむを得ず事前に連絡できなかった場合であっても、事後に必ず連絡するものとし、甲は当該事情の理由を問いたださない。
4. 年齢、性別、経験、容姿その他を理由とする差別的言動、及び相手の意に反する身体的接触その他のハラスメントを行わないこと。
5. SNS・その他の方法により、他のメンバーの氏名・連絡先・写真・動画等の個人情報を、本人の事前の同意なく公開しないこと。
6. 暴力団その他の反社会的勢力との一切の関わりを持たないこと。
7. 甲の活動の品位を損なう言動を行わないこと。

## 第10条（チーム内の交際）

1. **メンバー相互の交際は、原則として自由とする。** 甲は、交際の有無を理由として出場機会その他の取扱いに差異を設けない。
2. 前項にかかわらず、乙は、他のメンバーに対し、次の各号に掲げる行為を行ってはならない。
   1. 交際又は個人的な面会を断られた後、繰り返し誘う行為
   2. 学年、経験年数、チーム内の役割その他の立場を利用して迫る行為
   3. 相手の意に反して交際関係の有無を詮索し、又はこれを他のメンバーに流布する行為
   4. 交際関係の終了後において、相手が活動に参加しづらくなる言動
3. 本条の判断基準は、**相手が「やめてほしい」旨を一度でも示した場合は、直ちにこれをやめること**とする。
4. 本条に違反する行為は、第9条第4号のハラスメントに該当するものとして取り扱う。

## 第11条（未成年メンバーの保護）

甲には中学生及び高校生のメンバーが在籍しているため、第10条第1項は、満18歳未満のメンバーには適用しない。

1. **満18歳以上のメンバーが、満18歳未満のメンバーに対し、交際を求めること、及び個人的に二人きりで会うことを誘う行為を禁止する。**
2. 満18歳未満のメンバーとの個人的な連絡は、原則としてチームの連絡網により行うものとする。やむを得ず個別に連絡する場合は、保護者が内容を確認できる状態にしなければならない。
3. 送迎その他やむを得ず二人きりとなる場合は、事前に保護者の同意を得るものとする。
4. 本条に違反した場合、甲は第18条により強制退団を含む厳正な対応をとる。

## 第12条（保険及び自己責任）

1. 乙は、野球が身体接触及び用具の使用を伴うスポーツであり、負傷・疾病・物損等のリスクを内包することを十分に理解した上で、本契約に同意するものとする。
2. 本契約締結時点において、甲はチームとしてのスポーツ保険その他の傷害保険等に加入していない。
3. **乙のスポーツ安全保険その他の傷害保険への加入は、任意とする。** 保険料は年額2,000円程度（加入区分及び年度により異なる。）であり、乙の負担とする。
4. 中学生及び高校生のメンバーについては、福岡市の子ども医療費助成（高校生世代まで、通院は1医療機関あたり月500円まで、入院は自己負担なし）により自己のけがの治療費が実質的に補填されるため、**加入を要しないものとする。**
5. ただし、前項の助成の対象は自己の治療費に限られ、**他人に傷害を負わせた場合若しくは他人の物を破損した場合の賠償責任、及び後遺障害に対する補償は、その対象外である。** 乙は、この点を理解した上で加入の有無を判断するものとする。
6. **乙が保険に加入していない場合において、練習・試合・移動その他甲の活動に関連して発生した乙の負傷・疾病・用具の紛失若しくは破損又はその他一切の損害については、甲の故意又は重大な過失に起因する場合を除き、乙の自己責任において対応するものとし、甲は一切の賠償責任を負わない。**
7. 乙の保険加入の有無は、本契約書末尾の記入欄において確認する。
8. 甲が将来チームとしての保険に加入した場合、甲は速やかに乙に通知するものとし、以後の保険料等の取扱いについては別途協議の上決定する。

## 第16条（休会）

1. 乙は、仕事、学業、負傷その他の事由により一定期間活動できない場合、甲代表者に申し出ることにより休会することができる。
2. **休会の期間中は、月会費を要しない。**
3. 休会の申出は、休会を開始する月の前月末までに行うものとする。
4. 休会の期間は原則として最長6か月とし、これを超える場合は別途協議する。

## 第17条（退団）

1. 乙は、退団を希望する場合、いつでも甲代表者に対してその旨を申し出ることができる。退団の理由の説明を要しない。
2. **退団は、乙が前項の申出を行った月の翌月1日をもって、正式に成立するものとする。**（例：11月中に申し出た場合、12月1日付で退団）
3. 申出を行った月の月会費は発生するものとし、翌月分以降は発生しない。
4. 乙は、退団日までに、所定の「退団届」を甲代表者に提出するとともに、未払いの月会費及びグラウンド代を精算するものとする。
5. 退団届の提出がないまま第2項に定める日が経過した場合であっても、乙の退団の意思が明確であると甲が認めるときは、甲の判断により退団の効力を認めることができる。
6. 退団に伴い、既に納入された入会費、月会費及びグラウンド代は、理由の如何を問わず返還しないものとする。
7. 退団後、乙の成績データは、甲の記録として保管する。
8. 甲は、乙の再入団を妨げない。この場合、入会費を改めて申し受ける。

## 第18条（契約の解除、出場停止及び強制退団）

1. 乙が本契約又は規約の各条項に違反した場合、又は甲の活動に著しい支障を生じさせた場合、甲は、違反の内容及び程度に応じ、次の各号に掲げる措置をとることができる。
   1. 口頭又は書面による注意
   2. 一定期間の活動への参加の停止
   3. **リーグ戦への出場停止**
   4. リーグの登録メンバーからの除外
   5. **本契約の解除（強制退団）**
2. **乙がリーグの登録メンバーである場合において、本契約又は規約に違反したときは、甲はリーグ戦への出場停止を執行することができる。** 出場停止の期間は違反の内容に応じて甲が定め、乙に通知する。別途停止を命じない限り、練習への参加は妨げない。
3. **乙が本契約又は規約に違反した場合、甲は強制退団を執行することができる。** 特に次の各号に該当する場合は、強制退団の対象とする。
   1. 暴力行為に及んだとき
   2. 第9条第4号のハラスメントを行い、注意しても改まらないとき
   3. **第11条（未成年メンバーの保護）に違反したとき**
   4. 会費を長期間滞納し、連絡にも応じないとき
   5. 甲の名誉を著しく傷つけたとき
   6. 反社会的勢力との関わりが判明したとき
4. 甲は、前各項の措置を決定する前に、**原則として乙に理由を伝え、その言い分を聴取する。** ただし、暴力行為、ハラスメント、第11条違反その他緊急を要する場合は、先に活動への参加を停止したうえで事情を聴取することができる。
5. 乙が甲代表者からの連絡（電話・SMS・SNSのダイレクトメッセージ・電子メール等、通常の連絡手段をいう。）に対し、正当な理由なく30日以上応答しない場合、甲は、乙が退団の意思を有するものとみなし、乙に対する通知をもって強制的に退団処分とすることができる。この場合、乙は当該処分に対して異議を申し立てることができないものとする。
6. 本条に基づく契約の解除又は強制退団が行われた場合、乙は甲のメンバーの地位を失うものとし、既に納入された入会費、月会費及びグラウンド代の返還は受けられない。
7. 強制退団となった者の再入団は、原則として認めない。

## 第19条（契約期間）

1. 本契約の有効期間は、本契約締結の日から1年間とする。
2. 期間満了の1か月前までに甲乙いずれからも書面又はこれに準ずる方法による更新拒絶の意思表示がない場合、本契約は同一条件で更に1年間自動的に更新されるものとし、以後も同様とする。
3. 本条は、第17条に定める乙の退団の申出を妨げない。

## 第20条（契約書の保管及び変更）

1. 本契約書は、甲乙署名（又は記名押印）のうえ2通を作成し、甲乙各自1通ずつを原本として保有する。
2. 甲及び乙は、紛失・毀損に備え、保管用として本契約書のコピー（写し）を取得し、原本とは別に保管することができる。
