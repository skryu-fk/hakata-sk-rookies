# 規約改定に関する同意書

**博多SKルーキーズ 代表　柏木 海斗　宛**

私は、「博多SKルーキーズ チーム規約（第2版）」の全文を読み、内容を理解したうえで、これに同意します。あわせて、メンバー加入契約書 第12条第3項に基づき、**2026年12月1日をもって同契約書 第3条から第11条までが本規約の定めに置き換わること**に合意します。

とくに次の点を確認しました。

- 月会費は月額1,000円で、原則として毎月初めに支払うこと（第5条）／球場代にナイター料金があること（第6条）
- **スポーツ安全保険への加入は任意で、未加入の場合はけがをしてもチームが責任を負わないこと**（第9条）
- 医療費助成では、他人にけがをさせた場合などの賠償はまかなえないこと（第9条4項）
- 無断欠席・無断遅刻はなるべくしないこと。連絡が遅れても必ず伝えること（第11条）
- リーグ戦のメンバー登録がされるとは限らないこと（第13条）／退団は申し出た月の翌月1日に成立すること（第19条）
- 規約に違反した場合、リーグ戦出場停止または強制退団となる場合があること（第18条）
